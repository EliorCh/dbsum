# מדריך פתרון — מערכות בסיסי נתונים

מדריך ויזואלי אינטראקטיבי בעברית לקורס ״מערכות בסיסי נתונים״ (פרופ׳ גדעון דרור, המכללה האקדמית תל אביב־יפו).

- **מודל ER**: סימונים, שיטת 7 צעדים, פתרונות מודרכים עם תרשים חי
- **מודל היחסים**: מיפוי ER לטבלאות, אלגברת יחסים, תחשיב יחסים
- **SQL**: דוגמאות שרצות בדפדפן (sql.js), בדיקת תרגיל 3, ותרגיל 4 על בסיס הנתונים של הקורס
- **תלויות פונקציונליות**: סגור, מפתחות, כיסוי קנוני, מחשבון תלויות
- **תיכון ונרמול**: פירוק משמר מידע, BCNF, 3NF, שיטת הטבלה, 4NF
- **אינדקסים ו־hashing**: עץ B+ שלב אחרי שלב, extendable hashing, bitmap
- **בקרת בו־זמניות**: גרף קדימויות, 2PL, חותמות זמן, מנתח תזמונים
- **מטלות תרגול** עם בדיקה אוטומטית

אתר סטטי — אין צורך בהתקנה. פותחים את `index.html`.
